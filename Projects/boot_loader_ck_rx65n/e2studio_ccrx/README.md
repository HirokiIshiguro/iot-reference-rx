# boot_loader_ck_rx65n e2 studio project

This is the CC-RX e2 studio project for the CK-RX65N BG96 OTA boot loader.

Import this directory as an existing e2 studio project and build `boot_loader_ck_rx65n/HardwareDebug`.

The generated Motorola S-record is:

- `HardwareDebug/boot_loader_ck_rx65n.mot`
